# King & Sepal

King & Sepal is a cacao-based "melt-or-eat" bar brand: eat it like candy, or drop it
in a hot drink where it melts into a flavored creamer (French Vanilla, Caramel, ...).
Positioned as a small-batch, exclusive-drop brand in the spirit of Ffern.

Nothing is built or sold yet — this repo is the working plan for getting there.
